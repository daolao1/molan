# 墨澜 (Molan)

小说写作辅助应用 —— 像编程 agent 一样的对话式写作搭档,加上完整的设定库管理。配置你自己的 LLM API,数据全部存在本地。Flutter 构建,一套代码覆盖 Android / iOS / Windows / macOS / Linux。

## 功能

### 对话式写作 agent
- **章节 → 事件**的写作结构:每个事件有大纲与正文,承接前文语境
- 与 AI 多轮对话写作:AI 通过工具(读取/替换/续写/重写)**直接修改正文**,不在聊天里贴文字
- 工具调用全程可见:每步操作都是可展开的卡片,带参数与 diff(红删绿增)
- **回合末统一审批**:一轮的所有改动列成清单,逐条拒绝(自动回退)或全部接受
- 流式输出、可随时停止;**对话历史管理**:随事件持久化,可开新对话、归档找回、删除
- 长对话自动压缩成备忘;system 提示词静态化,**前缀缓存(KV cache)稳定命中**,省钱提速
- **持久高亮**:选中正文钉住高亮,编辑时自动跟随、被改动即自然消失;对话自动附带高亮片段,AI 也能用高亮帮你定位("帮我找到写雨的那段")
- 正文自定义选择菜单:复制 / 粘贴 / 全选 / 高亮,单击高亮可取消
- 写作中 AI 会自动记录新设定、人物关系与关联、同步大纲

### 设定库
- 人物 / 地点 / 物品 / 场景 / 世界观五类卡片,模板外的自定义字段也完整保存、可编辑
- **统一关联机制**:任意卡片间的定向关联,带描述、同对可多条(如 张三 → 藏剑阁"幼年在此学艺"),点击直达对方卡片;人物关系、场景归属、物品持有都是关联
- 人物卡**称呼系统**:按使用者区分(谁这么叫),多人共享或所有人通用,AI 写对白按视角用称呼
- **AI 生成与补充**:单卡生成(自由发挥)或定点补充(只写你提的),生成前自动检索现有设定保持一致
- 世界观批量生成:一句话生成多条,自动带描述关联相关卡片
- 悬浮球助手:任意界面唤起,用自然语言增删改设定,变更集勾选后应用
- 小说整体导出 / 导入(JSON)

### LLM 接入
- 兼容 OpenAI 格式,内置 DeepSeek / Kimi / 智谱 / SiliconFlow / OpenAI / Ollama 预设
- 写作与设定检索可分别配置独立 API(不配则共用主配置)

## 安装

从 [Releases](https://github.com/daolao1/molan/releases) 下载对应平台安装包。

### macOS 提示“已损坏”或被拦截？

安装包未经 Apple 公证（需付费开发者账号），下载后首次打开会被 Gatekeeper 拦截。解除方法，二选一：

```bash
# 方法一：移除隔离属性（路径按实际调整）
xattr -cr /Applications/molan.app
```

方法二：打开被拦后，去 **系统设置 → 隐私与安全性**，拉到底部点 **仍要打开**。

仅首次需要，之后正常使用。

## 开发

```bash
flutter pub get

```
